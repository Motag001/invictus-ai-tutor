# AI Data Science Tutor

AN AI-powered tutor that helps students learn
Data Science and AI Engineering concepts.

## Current Features

- Accepts student questions
- Generates AI responses
- Uses a pretrained language model
- Uses a custom prompt

## How to Run

Createa virtual environment:
python -m venv .venv

Activate it:
.venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

Run:
python app.py
